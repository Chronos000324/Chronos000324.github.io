Tukar gambar, cerita projek dan pautan. Perubahan disimpan terus ke GitHub kamu.

Token hanya berada dalam memori tab ini. Ia tidak disimpan dalam fail, cookies atau browser storage. Masukkan semula selepas refresh.

Cara sediakan token sekali sahaja
  1. Buka GitHub → Settings akaun → Developer settings → Personal access tokens → Fine-grained tokens.
  2. Generate new token. Pilih tempoh luput yang sesuai, contohnya 30 hari.
  3. Repository access → Only select repositories → pilih repository portfolio ini sahaja.
  4. Repository permissions → Contents → Read and write. Metadata read akan disertakan.
  5. Generate token, kemudian paste dalam ruang di atas. Jangan letak token dalam repository atau hantar dalam chat.
